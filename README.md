# Acuity Brands

Acuity Brands is a provider of lighting, lighting controls, building management systems, and location-aware applications for commercial, industrial, institutional, and residential markets.

## APIs

### Acuity Brands API

B2B REST APIs for Acuity Brands distributors covering inventory availability, order status tracking, product catalog, and web content. Enables integration of Acuity Brands data into distributor ERP, e-commerce, and ordering systems.

## Features

- **Inventory Availability** — Real-time inventory availability by product number and warehouse location with estimated ship dates.
- **Order Status Tracking** — Full order status data including estimated and actual ship dates, line item status, and order totals.
- **Shipment Tracking** — Carrier name, PRO number, and tracking URLs for all shipments associated with an order.
- **Product Catalog** — Search and retrieve Acuity Brands product catalog with specifications, certifications, pricing, and images.
- **Web Content** — Product and category web pages with metadata and content for distributor e-commerce integration.
- **Multi-Brand Coverage** — APIs cover all major Acuity Brands brands including Lithonia Lighting, Holophane, nLight, Juno, and Distech Controls.

## Use Cases

- **ERP Integration** — Sync inventory and order data into distributor ERP systems for automated stock management and order tracking.
- **E-Commerce Product Feeds** — Pull product catalog, images, specs, and pricing into distributor e-commerce storefronts.
- **Order Status Automation** — Automatically surface order status and shipment tracking to customers without manual ADC lookups.
- **Inventory Availability Checks** — Check real-time stock availability before quoting or placing orders for Acuity Brands products.

## Integrations

- **SAP** — Integrate Acuity Brands inventory and order data into SAP ERP for automated purchasing workflows.
- **Salesforce** — Surface product availability and order status within Salesforce CRM for distributor sales reps.
- **Epicor** — Connect Acuity Brands order status to Epicor distribution ERP systems.
